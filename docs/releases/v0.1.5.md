# Toccata v0.1.5

完成任务的过渡动画、完成自动取消置顶、主页更新橙点，以及全新的引导式 DMG 安装窗口。

## 更新内容

- **完成过渡动画**：菜单栏与工作台里完成任务时，整组任务平滑滑入已完成区，恢复待办时滑回；遵循系统“减少动态效果”设置。
- **完成自动取消置顶**：完成主任务时自动取消其置顶，已完成任务不再浮在顶部；旧版本遗留的“已完成仍置顶”会在下次完成时自动修复。只完成子任务不影响仍待办的主任务置顶。
- **更新橙点**：启动时静默检查新版本（仍不上传任务或键盘记录），发现新版时主页侧栏版本号旁显示橙色光点；关于页与侧栏共享检查状态，可直接下载并“安装并重启”。
- **引导式安装窗口**：DMG 打开后即是“把 Toccata 拖进应用程序”的图示引导，并附首次打开被系统拦截时的三步放行说明（点完成 → 隐私与安全性 → 仍要打开）。安装说明保留为隐藏文件。

## 下载与安装

适用于 **Apple Silicon Mac · macOS 13+**。版本 **0.1.5 / build 23**，使用 **macOS SDK 26.5** 构建。

下载 `Toccata-0.1.5-arm64.dmg`，按窗口图示将 `Toccata.app` 拖入“应用程序”并替换，然后退出旧版、从应用程序打开。已有任务和活动数据保留在原来的本机数据目录。

- v0.1.4 重启后会在侧栏看到橙色光点，可通过“关于 Toccata → 检查更新”下载新版，再点击“安装并重启”。
- v0.1.2、原 v0.1.3 build 20 及更早版本需手动覆盖安装一次。请从可写的应用程序目录运行，勿直接从只读 DMG 中更新。
- 首次打开若被拦截：在弹窗点“完成”，到“系统设置 → 隐私与安全性”点“仍要打开”，按提示确认即可，以后直接打开。
- 安装包采用 ad-hoc 签名，尚未执行 Apple 公证。
- 提供 `.sha256` 文件，可运行 `shasum -a 256 -c Toccata-0.1.5-arm64.dmg.sha256` 校验。

## English

Toccata v0.1.5 adds a completion transition, automatic unpinning on completion, an update beacon on the home sidebar, and a guided DMG install window.

- **Completion motion**: completing a task slides the whole group into the completed section in both the menu bar and the workspace, and back when reopened. Respects Reduce Motion.
- **Auto-unpin on completion**: completing a main task drops its pin so finished work no longer floats to the top. Legacy pinned-completed tasks are healed on the next completion. Completing a subtask leaves a still-pending parent pinned.
- **Update beacon**: a silent launch-time check (no task or keyboard data is sent) lights an orange dot beside the sidebar version when a newer release exists. About shares the same check and can download and install with a restart.
- **Guided install window**: the DMG opens with a drag-to-Applications illustration plus a three-step walkthrough for the first-launch Gatekeeper block (Done → Privacy & Security → Open Anyway). Installation notes remain included as a hidden file.

For **Apple Silicon Macs running macOS 13 or later**. Built with **macOS SDK 26.5**, version **0.1.5 / build 23**.

Download `Toccata-0.1.5-arm64.dmg`, drag `Toccata.app` into Applications as shown, quit the old app, and open it from Applications. Existing local task and activity data are preserved.

- On v0.1.4, relaunch to see the orange dot, then use About Toccata → Check for Updates → Install and restart.
- Users on v0.1.2, the original v0.1.3 build 20, or earlier must replace the app manually once. Run the installed app from a writable location, not the read-only DMG.
- If the first launch is blocked: click Done, open System Settings → Privacy & Security, and click Open Anyway.
- The package is ad-hoc signed and has not been notarized by Apple. A SHA-256 checksum file is included.

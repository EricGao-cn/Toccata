# Toccata Personal 1.1.0

本版本基于上游 v0.1.4，保留每日 Markdown 记录、任务和回顾功能。

- 关于窗口可手动检查 `EricGao-cn/Toccata` 的个人正式版本，并打开对应下载页。
- 检查会排除上游版本、草稿和预览版；不会下载或自动安装更新。
- 新增个人 GitHub Release 素材准备和草稿上传入口；正式发布仍需人工确认。
- 备份工具修复 SQLite 残留 SHM 的处理，并加强 WAL、回滚日志及旧备份检查。

首次使用可以从空的个人数据目录开始，原版 App 和数据保留，不要求迁移。安装前正常退出旧版及采集服务；后续更新个人版时备份其已有数据。降级 App 不会回滚数据库。本包为 Apple Silicon Mac 的本机 ad-hoc 签名构建。

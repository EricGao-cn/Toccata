# Toccata Personal 1.2.0

个人版本 **1.2.0 / build 4**，基于上游 **v0.1.5 / 40d0641**，保留每日 Markdown 记录、任务管理、回顾及独立个人数据目录。

## 更新内容

- **完成过渡动画**：在菜单栏和工作台完成任务时，整组任务平滑移入已完成区；恢复待办时移回，并遵循系统“减少动态效果”设置。
- **完成后取消置顶**：完成主任务会取消其置顶；每次完成任务也会清理旧版本遗留的已完成主任务置顶。只完成子任务时，仍待办的主任务继续置顶；恢复任务不会还原已取消的置顶。
- **个人版更新橙点**：启动时匿名检查 `EricGao-cn/Toccata` 的个人正式版本，发现新版时在侧栏版本号旁显示橙点。侧栏与关于页共享检查状态，仅打开个人版下载页，下载安装仍由用户手动进行。

版本检查只读取发布信息，不发送任务、每日记录或键盘数据；排除上游版本、草稿和预览版。每日 Markdown 文件、任务和键盘历史继续保存在原有 `Toccata-Personal` 数据目录。本次没有新增数据库 schema 迁移，也不要求迁移上游数据；完成任务时会按上述规则更新置顶状态。

## 安装与更新

安装包适用于 **Apple Silicon Mac、macOS 13 及以上**，固定使用 **macOS SDK 26.2** 构建，为 ad-hoc 签名，未做 Developer ID 公证。提供 `Toccata-Personal-1.2.0-arm64.dmg`、SHA-256 校验文件及发布清单。个人 DMG 继续使用独立打包流程与安装说明。

更新已有个人版前先备份数据，完成保存并正常退出 App 及采集服务，再将 DMG 内的 `Toccata Personal.app` 替换到 `~/Applications`。推出镜像后从安装位置启动，核对版本、任务、每日记录和键盘历史。既有个人版数据目录继续使用，降级 App 不会自动回滚数据库。

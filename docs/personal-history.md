原记录日期为 2026-11-01：SDK 26.2 已能构建并运行隔离任务开发版；当时通过 39 项 Python 测试（含 14 项个人配置测试）、28 项 Rust 测试及构建/签名检查。测试覆盖 worktree 初始化、工具链共享、身份隔离和外置数据保留。当时本机只有 Command Line Tools，未运行 XCTest。

## 本地稳定分发准备阶段

先完成了 `personal-v1.0.0` 的本地正式包，以及离线备份、迁移副本、成对安装、回滚与中断恢复工具。`personal-v1.1.0` 随后接入个人 GitHub 发布和检查更新，安装包最初由本机生成，再补充 DMG 分发并保留 ZIP。

早期文档中的“尚待实现的个人稳定分发约定”“本轮允许做的准备”“本轮只实现和隔离验证，不实际安装”“未来正式迁移时……本轮不执行”等，描述的是当次任务的边界。它们不再用于判断当前功能是否可用，实际操作仍以当次授权和当前工具检查为准。

首次个人安装选择全新的 `Toccata-Personal` 数据目录，保留原版 App 和数据，没有导入上游记录。这是一次安装选择，不是后续更新必须清空数据的步骤。

## 2026-11-06：个人版云端发布与日常更新

`personal-v1.1.1 / build 3` 基于上游 `v0.1.4`，完成 Actions 构建、草稿上传、核验后正式发布，并完成已有个人版的手动 App 更新。原个人标签未移动，原版 App、原数据及既有备份保留。

首跑补齐了与上游完全一致的缺失基线标签，并解决上游自动安装正向测试与个人禁用安装策略混用的问题。修正 Actions 编排时应用源码和个人固定标签保持不变，分别记录应用源码提交与工作流提交。一次上传前 API 超时后，确认没有残留草稿，再只重跑失败 job 并复用原 artifact。

该次 App 更新在明确授权下只替换程序，沿用个人数据目录，未新建配对回滚快照。替换前后核验了数据保留情况；这一单次免备份选择不代表后续默认免备份，也不提供数据库回滚保障。

[该版本发布流水线](https://github.com/EricGao-cn/Toccata/actions/runs/42190941623)记录了 153 项脚本测试、30 项个人 core 测试、381 项常规 Swift 测试（1 项可选测试跳过）和 4 项个人策略测试，均无失败。交互式 WebKit 测试未执行。

只检查测试的日常 CI 已合入个人主线并[首次运行成功](https://github.com/EricGao-cn/Toccata/actions/runs/42237888936)。该次记录为 163 项脚本测试、30 项个人 core 测试、381 项常规 Swift 测试（1 项可选测试跳过）和 4 项个人策略测试，无失败；artifact 数量为 0，Release、草稿、附件与标签未变。

本机缺少完整 Xcode 与云端已通过 XCTest 可以同时成立。测试数量和环境随提交变化，以对应提交的 CI 日志为准，历史数量不作为后续固定验收门槛。机器诊断、安装记录和备份保存在本机，不作为新 worktree 的重建依赖，也不将其内容提交到公开仓库。
